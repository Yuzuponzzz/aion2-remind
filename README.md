〇これ何〇 AION2公式サイトの更新情報を公式APIで取得→WebHookを使用して任意のDiscodeチャンネルに投稿します。 GitHubActionsを使用して自動更新するので、導入後は手動での操作は一切不要です。 また、重複通知を避けるために一度取得した更新情報はURLをリストアップして保存してあります。

〇導入方法〇 ご自身のリポジトリにフォーク後、Settingタブから任意のチャンネルのWebHookURLを登録してください。 正常に登録できているか確認したい場合はActionsタブからテスト通知が送信できます。
